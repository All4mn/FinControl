## Atividades Realizadas

A minha contribuição durante a primeira fase do andamento do projeto foi marcada pela criação do banco de dados seguindo o diagrama entidades relacionamento definido em equipe, a criação e pré preenchimento das tabelas e a criação de uma função para monitorar a tabela `transacoes` e registrar logs sobre a movimentação da mesma, juntamente com a realização do upload do banco de dados em uma plataforma serveless (Neon) e o auxilio para os outros membros com a configuração do banco de dados pelo DBeaver. 

Na parte voltada ao Backend, em conjunto ao trabalho prévio que o Hiago disponibilizou, pude ajudar a construir a arquitetura do backend, separando as pastas para se encaixar ao modelo MVC e criando arquivos para serem seguidos como exemplo, novamente auxiliando os outros integrantes a respeito de lógicas das Pools e querys.

## Conhecimentos Adquiridos

Definitivamente um dos projetos que eu mais estive ativo na produção, foi de enorme ajuda para desenvolver meus conhecimentos na parte do backend e do banco de dados. Des da parte do conhecimento com redes serveless (neon) à containers (docker - nao utilizado) até mesmo com lógicas SQL, criação de bancos de dados relacionais, criação de triggers e functions e manipulação com diferentes tipos de valores.

Creio que foi de extrema ajuda estar em duas funções (banco de dados e backend) para meu aprendizado e para meu senso de responsabilidade.

##  Dificuldades Encontradas

Algumas das maiores dificuldades vieram logo no nascimento do projeto e na hora de designar cargos para cada membro, tive que reaprender toda uma matéria inteira de banco de dados para poder fazer uma estrutura de banco de dados de fosse coerente e coesa com o que planejamos para o FinControl. Além de ter que pegar para aprender como se fazia uma série de requisições pelo VSCode e após tudo isso, repassar para meus companheiros de equipe para garantir que ninguem ficasse por fora e/ou o projeto ficasse monopolizado.

Ferramentas de Inteligencia artificial foram de extrema ajuda nesse projeto, além de pesquisa por meio de forums e vídeos didáticos.
